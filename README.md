# 易读 · YIDU 0.8.9

支持普通 HTTP / HTTPS 网页的 Chrome / Edge 双语翻译扩展，并保留亚马逊商品调研功能。默认 Google 免费翻译为简体中文，无需 Key；支持批量保存视频及字幕，并可将字幕合并到视频画面。源码基于 KISS Translator 请求池、BilingualTube 字幕预取模块改编，采用 GPL-3.0-only。

## 安装／更新

1. 解压 dist/yidu-0.8.9.zip；在 chrome://extensions 或 edge://extensions 开启开发者模式，加载包含 manifest.json 的目录。
2. **禁用旧版，避免两个版本同时运行。** 若原来直接加载本项目 extension 目录，点扩展卡片的重新加载按钮即可。
3. 新版扩展到所有普通 HTTP / HTTPS 网站。浏览器若提示访问范围变化，请允许该扩展在需要翻译的网站运行；希望所有网页可用时，网站访问权限设为“在所有网站上”。
4. **刷新已经打开的网页**。点击网页上的“易读”图标或工具栏按钮，开启双语。此后同一标签页跳转到商品、店铺、首页、搜索页或其他网站会延续翻译状态。新标签页默认使用最近的开启／关闭选择。

## 0.8.9 通用正文预译与延迟模块加载

- **其他网站也提前预译**：普通网页中已经提供的下方正文继续后台翻译；新增对闭合 details、正文内明确由展开按钮控制的折叠区域、浏览器延迟渲染正文的预译。保持原来的折叠状态，先缓存译文，展开后直接显示，无需再请求一次。
- **亚马逊延迟模块**：开启双语后，使用当前商品页自己的评论加载器提前读取摘要、买家媒体等延迟模块，读取后自动参与翻译。不会滚动页面、打开 See all、播放视频或提交评论。原本已加载的描述和评论仍走通用翻译队列。
- **首屏优先、限制资源**：正常正文优先，折叠正文预译最多占 2 个请求，总并发不超过 6；每页预译折叠正文最多 100 段／60,000 字符。超出的部分在显示时照常翻译。关闭双语或跳转后，不再启动旧页面任务。
- **边界**：尚未从服务器提供的内容需要匹配该网站的加载方式，目前仅新增上述亚马逊适配；不会宣称所有网站都能提前取全，也不会自动跨分页抓取全部评论或无限滚动列表。图片中的文字仍通过右键图片翻译处理。

更新到 **0.8.9** 后重新加载扩展并刷新网页。预加载和预译随网页双语开关启停，不改变标题布局、媒体保存或字幕设置。

## 0.8.8 标题布局独立修复与后台预译

- **标题始终位于右侧价格上方**：布局修复与翻译开关分离，在网页初始化时独立运行。关闭双语、切换翻译引擎、设置读取失败或尚未完成，都不会把标题移回主图上方。兼容页面后续加载和桌面布局重排。
- **无需滚动触发翻译**：开启双语后，优先处理当前屏幕，再在后台翻译页面已加载的其他文字。滚动后优先处理新进入视野的待译内容，已翻译部分继续复用；后续新增内容自动补译。
- 网页尚未加载到 DOM 的内容，仍需等网站实际加载后才能翻译；不会通过强制滚动、自动点击或播放去触发加载。隐藏、输入框和播放器字幕继续由原有专用规则处理。

更新到 **0.8.8** 后重新加载扩展，并刷新商品页。标题修复不需要开启翻译；后台预译随网页双语开关启停。

## 0.8.7 买家视频完整列表与播放界面修复

- **无需点击 See all**：在 Customer photos and videos 的视频封面上右键保存时，主动读取当前商品的买家视频分页列表；不打开图库、不自动播放。合并去重后展示标题、封面、时长，并带上每段视频自己的字幕地址。See all 内部的缩略图也可直接右键保存。
- **字幕窗只在播放时显示**：未播放、暂停、结束、视频隐藏或切到其他标签页时隐藏；预取完成、重试或迟到的翻译响应不会强行弹出。关闭后保持关闭，静音循环自动预览不触发字幕窗。
- **商品标题布局**：兼容亚马逊把标题组放在主图上方的新布局。开启双语时，将原有标题组移到右侧空置的标题栏，保留链接与交互；关闭双语或切换到单栏时恢复原位。

更新后重新加载 **0.8.7**，刷新商品页，再右键视频封面创建新的保存任务。媒体清单使用当前页面的正常访问权限；最多读取 12 页／300 条记录，保存页最多展示 100 个媒体候选。列表按商品隔离，页内缓存 30 分钟；服务失败保留已取得的视频，不猜测其他视频地址。

## 0.8.6 买家秀直接保存与界面精简

- **买家秀无需先播放**：识别 Customer photos and videos 轮播中视频按钮已提供的 `data-url`、封面和时长，右键封面或播放图标即可进入保存页，并预选对应视频。列表已加载的其他买家视频也可勾选。兼容旧版延迟媒体属性和明确的视频标识；无法确定对应关系时不猜测或下载其他视频。
- **整张卡片勾选**：点击标题、封面或空白区域选择／取消；右上角空圆与绿色勾平滑切换。移除“加入批量下载”文字行，保留键盘操作；卡内画质和预览按钮独立操作，拖动选字不误选。
- **精简工具界面**：工具栏只保留网页双语开关和翻译设置。浮动面板保留语言、引擎、开关、重试、设置和进度；移除评论样本、图片选择、商品视频控制及 SRT/VTT 导入区。图片继续右键翻译，视频保存选项集中在保存页。
- **移除录制**：删除标签页音频录制与相关消息处理，不再申请 `tabCapture` 权限。自动字幕文稿、已有字幕下载、图片 OCR 仍保留。
- **保存页文案**：移除指定的重复说明、“无需先播放”卡片提示及“任何播放器都能显示”表述；错误和必要下载状态仍显示。

更新后重新加载 **0.8.6**，刷新原商品页，并重新右键创建保存任务。

## 0.8.5 列表右键、批量下载和字幕合并到画面

- **列表缩略图也能保存视频**：在 Product Videos 右侧缩略图或标题链接上右键，选择“保存视频（易读）”。识别所点视频的独立地址，并在下载页预选该视频；仍可单独保存封面图片。不会把当前播放器的视频或字幕套给其他缩略图。
- **勾选多个视频下载**：每张卡片可勾选，支持全选／清空。点击“下载勾选的视频”按队列保存，逐视频显示结果；单个失败继续下一项，可随时取消后续任务。批量采用每段视频推荐画质，单个保存仍可自选画质。每个视频默认 6 路并行下载分段，字幕与媒体同时准备；转换器逐个处理，避免多开大内存任务。
- **默认合并字幕到画面**：字幕真正绘制到视频画面中，播放器无需加载或打开字幕轨，无法单独关闭。需要重新编码，耗时比普通保存长；中文字体随插件提供，本机处理，不上传视频。
- **也可不合并**：选“分开保存 MP4 和 SRT（下载更快）”，保留快速无损封装／兼容 MP4 直接保存。播放器没有自动加载时，手动加载同名 SRT。字幕内容可选双语、仅原文或不读取。
- **文件自动配对**：视频与取得的 SRT 自动同名保存到默认下载目录的 `易读/日期-任务编号/`，批量共用一个文件夹。成功后点击“在文件夹中显示”快速打开；不再为视频逐个弹出保存位置对话框，图片保留原来的另存方式。
- **结果如实提示**：字幕缺失、只取得部分字幕或字幕文件保存失败，会分别提示；已经成功保存的视频仍可打开所在文件夹。网页未提供的口播字幕不会凭空生成；无字幕视频仍需另行语音识别。

更新后重新加载 **0.8.5**、刷新来源页面、重新右键创建下载任务。旧文件的字幕不会自动改变，需重新下载并选择合并。本版不新增扩展权限。

## 0.8.4 自动读取商品视频列表与下载字幕修复

- **未播放的视频也能下载**：直接读取当前 Amazon Product Videos 组件已经提供的完整列表、标题、封面、时长、媒体和字幕地址，无需逐个点击播放。支持列表 DOM、data-video-items、a-state 数据，最多 100 段；不会自动点击或播放视频。卡片立即展示已有信息，再补齐画质；网站尚未下发的视频无法凭空列出。
- **每段视频带自己的字幕**：修复只有当前播放器的字幕能进入下载、其他候选视频没有字幕的问题。选择列表中的未播放视频，也会读取它自己关联的 VTT 并翻译，写入默认开启标记的 MP4 字幕轨。严格核对字幕与所选媒体地址，不混用其他视频文稿，保留快速并行下载和无损封装。
- **保存后可核对**：下载页显示实际写入的字幕条数，并可展开检查原文和译文；未取得字幕或只有网站的“No spoken audio”提示，会明确说明，不声称已获取整段讲解。

字幕是可开关文字轨：播放器中选择字幕／CC 开启。部分播放器不支持 MP4 内嵌字幕，可用“另存字幕（SRT）”加载；网页没有提供口播文稿的视频仍需另行语音识别。旧版已保存的无字幕文件需要重新下载。

更新后重新加载 **0.8.4**、刷新商品页，再右键打开新的下载页；本版不新增扩展权限。

## 0.8.3 视频卡片与画质选择

- **按视频选择**：下载页改为缩略图卡片，显示已取得的标题、时长、分辨率和可选清晰度。与右键播放器直接绑定的资源标记“当前视频 · 优先选择”；其他资源保留“页面候选 · 请核对画面”。网站没有提供的标题明确标为缺失，不拿商品标题或文件名冒充视频标题。
- **合并同一视频的画质**：只有总播放清单实际列出的子清单才归为同组。相同文件名的 MP4 仍独立显示，避免选错内容；原资源地址保留在可展开的手动选择区。先识别到子清单时，分组不会悄悄改变已选地址。
- **推荐 720p**：优先推荐可保存的 720p，兼顾清晰度与速度；没有 720p 时推荐最接近的可用较低画质，只有更高画质时选其中较低的一档。可手动改为 1080p 等其他画质，保存按钮上方明确显示将保存的视频和实际选择的画质。
- **真实封面与有限预览**：优先用当前视频的封面；没有封面的 HLS 仅读取首个片段生成缩略图，每个预览最多 12 MB、20 秒，按可见卡片加载。MP4 读取自身时长／尺寸并可播放核对。预览失败会显示原因，不借用其他视频的图片；切换／关闭时释放旧预览。

总清单中选择 720p，与直接选择它声明的同一个 720p 子清单，最终视频内容和画质相同；前者方便切换画质。不能仅凭名称断定两个地址属于同一视频。

更新后重新加载扩展并刷新原网页，再次右键创建新的下载页；工具栏版本应为 **0.8.3**。本版不增加扩展权限，新资源域名仍按需授权。

## 0.8.2 自动识别语言、并行下载和保存字幕

- **自动识别源语言 → 简体中文**：结合浏览器本机语言识别与网页／段落 `lang`，在面板显示来源语言。逐段翻译继续使用 Google 自动识别，支持混合语言网页；修复纯汉字日文标题被当成中文跳过的问题，也支持明确标记为繁体中文的网页转简体。不会根据域名推断作者国籍，未标注且缺少上下文的短汉字文本仍可能有中日文歧义。已有中文不重复翻译，翻译服务不支持的语言无法保证效果。
- **视频分段并行下载**：默认同时下载 6 段，可选择 8／3／1 路。每个片段单独下载、重试，全部成功后按播放清单的顺序合并。下载、字幕读取翻译、本机视频引擎准备同时进行；界面显示速度及片段进度。兼容音视频无损封装，已完整且兼容的普通 MP4 可直接保留，避免额外处理。实际速度仍取决于 CDN、带宽和转码需求。
- **MP4 内嵌字幕 + SRT**：保存页默认“原文 + 简体中文”，读取所点视频的完整 VTT／SRT 或所选 HLS 清单的字幕，复用已预译的内容，写入可开关的 MP4 文本字幕轨。原视频已有的支持的文本字幕也会保留，不再统一丢弃。可选“仅原文”加快准备，或“不读取网页字幕”。完成后可“另存字幕（SRT）”，与视频同名放在同一文件夹；播放器未自动显示时，在字幕菜单选择内嵌轨道，或加载 SRT。
- **字幕失败可重试**：部分字幕、翻译失败、字幕域名未授权、不能可靠对齐的时间轴会明确说明。可授权后重试字幕，复用已下载视频，不重新下载全部片段。网页只提供画面中的文字或无法获取完整轨道时，本功能不能凭空生成完整字幕；无字幕视频仍需使用原有语音识别功能。
- **图片不重复下载**：预览与保存使用同一次文件读取；同一保存页再次保存会复用已准备文件。JPEG 不重新编码，GIF 保留动画；其他可解码格式仍生成真正的 JPG。视频已准备完但取消系统保存对话框后，再次保存也可复用本页结果；关闭保存页后释放缓存。

更新后重新加载扩展，**刷新已有网页**，工具栏应显示 **0.8.2**。本版不新增权限；字幕来自新的资源网站时仍可能出现按需读取授权。正常网页上的视频双语文稿窗口保留原来的行为。

## 0.8.1 Blob 视频保存与媒体捕获

修复只在右键时读取播放器接口／浏览器性能记录，导致视频已播放却没有保存地址的问题。现在从页面开始加载时记录媒体 URL 与 Content-Type，独立缓存可保留已从性能记录中消失的清单；后台还可观察 Amazon.com 发起、指定媒体 CDN 返回的请求，补充不经过页面 fetch/XHR 的资源。仅记录媒体候选，不读取正文、Cookie 或修改请求。后台缓存按标签页与框架隔离，导航／关闭时清理，最长保留 30 分钟，浏览器重启后清空。

右键视频仍优先使用与所点播放器直接绑定的地址。只能找到页面网络候选时，保存页要求先手动选择并核对资源，再选择清晰度并保存 MP4；不会把“最近加载”当成“就是所点视频”。修复播放器初始化早期返回空地址便立即失败的问题，改为短时重试。无资源时提示刷新并重新加载视频，不再据此断言网站禁止保存。

**更新后请重新加载扩展、刷新商品页，再打开视频播放后保存。** 已经加载完的请求不能倒退捕获。新版增加只读 webRequest 权限和 Amazon.com 网站访问，用于上述后台捕获；浏览器若暂停扩展，请确认更新权限。网页权限不足、匿名 Worker 无法确认归属、直播、加密或未支持的分段格式不保证保存；可读取的完整文件／非加密 HLS 沿用本机 MP4 转换。

## 0.8.0 完整字幕文稿与媒体保存修复

视频使用独立的“易读 · 视频双语文稿”窗口：读取完整字幕后集中翻译，一次显示所有时间戳、原文和译文，可自由滚动阅读。播放进度、原字幕重建或同一句重复出现都不刷新已经完成的文稿；不再向原播放器黑框插入翻译，也不逐句暂停视频。

- **自动显示**：仅在视频播放时出现；暂停、结束、播放器关闭或移出屏幕时隐藏。手动关闭后不会被再次播放强制打开。
- **手动控制**：网页面板中的“打开／关闭字幕文稿”可随时切换，也能在暂停时主动打开阅读。窗口支持拖动、收起、复位、关闭和重试。
- **完整字幕优先**：修复自定义播放器识别及多个视频来源混用，读取对应视频的 VTT。若站点只提供当前片段，会明确显示“尚未取得完整字幕”，保留已收集内容并继续查找；无法提前显示站点尚未提供的句子。
- **主图右键保存**：商品主图上有透明放大交互层时，也可选择“保存图片（易读）”；按实际右键位置识别原图。图片切换后需重新右键，避免保存错图。
- **图片预览与位置**：保存页先预览所选图片，转换完成后显示实际保存结果及尺寸。下载成功后点击“在文件夹中显示”，打开系统文件夹并定位文件；取消或失败时不会启用。
- **Blob 视频保存**：通过具体视频元素读取播放器公开的实际媒体地址，不再要求固定的 Video.js 类名；修复多个播放器／旧桥回复混用。支持的 HLS 点播继续整理为 MP4。未公开媒体源或不支持的流格式会说明原因。

## 0.7.0 独立字幕窗口与媒体保存

**视频双语默认显示在“易读 · 视频字幕”独立窗口。** 窗口固定尺寸，按住标题即可拖动，也可收起／展开、复位。长句在窗口内滚动，不撑高原播放器的黑框。完整字幕提前翻译，按时间轴切换；英文不变时复用同一中文。静音或原字幕节点暂时重建时，保留上一句并标明“等待下一句”，直到下一条出现。拖动进度后立即匹配缓存；没有完整字幕时仍使用当前屏幕字幕兜底。面板中的“字幕悬浮窗”按钮可展开该窗口。

右键保存：

- **保存图片（易读）**：**GIF 保留原格式与完整动画**；其他图片统一保存为 **JPG**。原 JPEG 保留字节，PNG、WebP、AVIF、BMP、ICO、SVG、TIFF 等先解码再编码为真实 JPG，保留尺寸；透明区域填充白色，TIFF 取第一页。转换质量 0.94；不执行 OCR。输入最多 32 MB，需重编码图片最多 2,400 万像素／单边 16,384 像素；无法解码或超限会报错，不会仅改后缀。
- **保存视频（易读）**：请先加载／播放视频，在视频画面上右键。打开保存页后，选择资源和清晰度，再保存。视频覆盖层有时属于网页菜单，此菜单也提供同名入口；在非视频区域选择会提示重新右键视频。
- 普通 MP4、WebM、MKV、MOV、OGV，以及支持的 HLS 点播，保存结果统一为 **MP4**。Amazon Product Videos 的 Blob 播放器通过对应 Video.js 实际源找到 HLS。H.264／AAC 编码优先无损封装，其他支持的编码转为 H.264／AAC；核对音轨和时长、将索引放在文件头以方便播放和拖动。原本无音轨的视频保持静音。转换不是改后缀，且全部在本机完成。
- 找不到与所点视频直接绑定的地址时，显示当前页面发现的候选，必须手动选择核对；不会自动选取广告或其他视频。来源切换后原右键请求会失效，需要重新右键。
- 下载页显示读取、封装／转码、校验进度，并支持取消；取消转换会真正终止工作线程。视频输入和输出各最多 256 MB，单次转换最长 20 分钟；转码速度取决于清晰度、长度和电脑性能。新资源域名需要浏览器读取授权，下载完成前保持该页打开。图片最多 32 MB，视频最多 256 MB，HLS 最多 2,000 段。直播、加密／DRM、DASH、独立音轨及未支持的复杂分段格式会明确提示；不提供绕过保护或自动解密。

本次参考 [猫抓的开源实现](https://github.com/xifangczy/cat-catch) 的媒体分类、来源归属和分段下载流程，按本插件需求重写精简模块，未加入全站流量监听或密钥抓取。

## 当前使用：翻译图片

右键 Product description 或其他网页图片 → **翻译图片（易读）**。阅读框在图片旁显示识别原文和中文，可滚动查看；关闭阅读框后保留原图。主要识别英文，小字、复杂照片背景、艺术字、型号和数字应对照原图核对。原图在本机识别，识别后的文字发往 Google／所选翻译接口。

图片 OCR 支持已获读取权限的 HTTP / HTTPS JPG/JPEG、PNG、WebP、GIF（静态帧）、AVIF、BMP、ICO、SVG。OCR 暂不支持 HEIC、TIFF、内嵌 data、Blob、本地文件，以及需 Cookie 登录或重定向才能下载的图片。遇到新图片域名时，右键操作可能要求访问授权。图片保存与 OCR 的格式支持范围分别处理，GIF 保存仍保留动画。

浏览器启动／插件更新时自动预热本机 OCR，随后复用同一引擎。预热尚未完成时会等待首次初始化；英文字库和 Wasm 随扩展打包。单图最多 12 MB、24M 像素；OCR 缓存最多 100 张／30 天，可在设置清空。

## 评论使用

开启网页双语后，滚动到评论区即可阅读原文和译文。折叠、展开或新加载的评论继续参与网页翻译，面板只显示整体翻译进度，不再提供评论数量、样本统计、分析或导出入口。

已加载的评论会提前翻译，支持的折叠正文先预译缓存；亚马逊商品页的评论摘要、买家媒体等延迟模块使用页面原生加载入口提前获取。不自动跨页收集全部评论；其他网站尚未提供的内容需要该网站的加载适配。

## 视频播放与字幕下载

### 网页播放

播放 Product Videos 中的视频，默认读取该视频已有字幕并集中翻译，一次显示双语文稿。独立字幕窗随播放出现，暂停或结束时隐藏；可在窗内重试、收起或关闭。设置中可关闭自动视频文稿。普通网页面板不再放置视频控制或字幕导入按钮。

若播放器只公开滚动字幕片段，文稿会标明尚未取得完整字幕并保留已收集内容。首次准备时间取决于字幕长度和网络。原生 video 元素全屏可能遮挡自定义文稿窗，可退出全屏阅读；播放器容器全屏支持叠加。

### 保存视频和字幕

1. 在视频画面或已识别的视频列表缩略图上右键，选择 **保存视频（易读）**，进入保存页。
2. 核对视频封面、标题与时长；点击卡片勾选，可一次下载多个视频。批量采用各视频推荐画质，单个保存可另选画质。
3. 选择字幕内容：原文＋简体中文、仅原文，或不读取字幕。
4. 选择字幕保存方式：**合并到画面**会重新编码，将文字绘制进 MP4，播放时直接显示；**分开保存**速度更快，播放器需要自动或手动加载同名 SRT。
5. 视频与取得的 SRT 自动同名保存到默认下载目录的 **易读／日期-任务编号** 文件夹；点击“在文件夹中显示”打开位置。

下载使用视频已提供的字幕轨、字幕文件或取得的字幕快照。未取得字幕时会明确提示；当前保存页不会自动做语音识别。字幕合并需要本机重新编码，处理时间和文件体积可能增加。录制音频、导入 SRT/VTT 和双语 TXT 导出入口已从当前界面移除。

## 本机语音识别工具（保留）

项目保留独立文件转录服务和转录接口配置，详见 [本机语音识别说明](docs/LOCAL_ASR.md)。当前版本没有面向用户的转录启动按钮，填写接口并保存设置也不会自动转录网页视频。下载视频和字幕的流程不调用该服务。

需要识别无字幕文件时，可单独运行本机服务，通过文档中的文件上传示例调用；服务返回识别文本和时间戳。此工具不自动生成中文译文或 SRT。项目尚未下载模型或实测其识别效果。

## 准确度

免费模式保护电商术语表中的完整词组，例如区分 water resistant（防泼水）和 waterproof（防水）；服务丢失保护标记会报错，不会静默给出错配术语。保留原文核对尺寸、型号、认证、否定和限制条件。

AI 精译需要自行配置 Chat Completions 完整 URL。AI 请求附带商品标题和术语表，并要求保留数字、单位、品牌和型号；输出仍需核对原文。没有做与 Trancy 的同环境速度／准确度对照，不承诺同等性能。

## 数据范围

开启后，页面已提供且符合条件的文字（包括视野外和支持的折叠正文）直接发往 Google 或所选 AI 服务，当前屏幕优先，其余后台预译。支持的亚马逊延迟模块由网站原生加载器沿用当前访问状态读取，随后按相同规则翻译。扩展不提取 Cookie，不翻译输入框、密码框或编辑区；账户、订单等页面上已经显示的文字也可能参与翻译，可在面板关闭。API Key 只存浏览器本地、不云同步。当前版本不采集标签页音频。保存视频使用已取得的字幕，字幕文字按所选方式发送到翻译服务；视频封装与字幕合并在本机完成，不发送到语音识别接口。若另行调用文件转录工具，文件会发送到你指定的转录服务；本机服务在本机处理。缓存可在设置清除。

## 开发与验证

运行时为原生 JavaScript，无远程可执行代码、无需构建。

    npm install
    npm test
    npm run check
    npm run package

OCR 和媒体转换依赖均已锁定并随扩展打包；可运行 `npm run vendor:ocr`、`npm run vendor:media` 重新复制资源。媒体转换使用本地单线程 FFmpeg WebAssembly，保存时不下载远程程序、不上传媒体。转换引擎约 31 MB，已包含在安装包内；普通图片无需启动该引擎，TIFF 原生无法解码时才使用兜底。

[验证记录](docs/VALIDATION.md)区分了真实页面测试、模拟服务测试和未覆盖范围。亚马逊国家站与 A/B 布局持续变化；DRM、封闭 Shadow DOM 与视频烧录字幕 OCR 未支持。
